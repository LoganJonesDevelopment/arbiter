# Safe iteration

Create a Python 3.12 environment, then install `backend/requirements-dev.txt`. From `backend/`, `python -m unittest discover -s tests -v` is the fast backend loop. For full backend coverage, run `coverage run -m unittest discover -s tests -v` followed by `coverage report`. Tests own in-memory SQLite databases, use in-process HTTP transport, force collection off before importing application modules, and reject network connections. No personal market database, credential, or real collector is required. CI runs the same suite and the existing frontend lint/build commands.

The fixtures cover configured fee arithmetic, purchase direction, fee-consumed discounts, theoretical/shorting/thin-liquidity gates, momentum snapshots, persisted opportunity upserts/expiry, event matching, cross-exchange persistence, API filters/pagination/counts, history/pruning, and disabled collection. They verify code contracts, not current exchange fee policy or actual trading profitability. Three explicitly expected failures reproduce unresolved financial-result defects; an unexpected success fails the suite so their markers must be removed when corrected. See `KNOWN_RESULT_DEFECTS.md` before relying on executable labels.

For collection-free local API development, from `backend/` run `COLLECTION_ENABLED=false DATABASE_URL=sqlite+aiosqlite:///:memory: uvicorn arbiter.main:app --host 127.0.0.1 --port 18888`. It binds loopback and discards its empty store when stopped. Do not point this command at an existing database. `/api/scan` returns 503, startup schedules no collector, and direct scheduled/manual collection is rejected or skipped. `/api/reanalyze` still operates on the explicitly selected disposable data. Production collection stays enabled by default; this change does not restart or alter any running deployment.

Frontend quick checks remain `npm --prefix frontend run lint` and `npm --prefix frontend run build`. Browser interaction coverage remains a separate gap. The full backend suite does not replace a provider contract check; no live provider check is part of ordinary iteration.
